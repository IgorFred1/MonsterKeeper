# Monster Keeper

Monster Keeper é um projeto criado a partir da minha paixão por jogos de RPG, especialmente aqueles com um estilo mais clássico e nostálgico.

A ideia surgiu da vontade de criar meu próprio jogo, unindo minhas ideias, criatividade e ferramentas de inteligência artificial para desenvolver uma experiência divertida e envolvente.

## Ferramentas utilizadas no desenvolvimento

O projeto começou com o auxílio do Lovable, mas, com o avanço do desenvolvimento, passei a utilizar o GitHub Copilot como ferramenta de apoio.

Essa mudança me permite explorar melhor o código, entender como cada parte do projeto funciona e ter mais controle sobre o desenvolvimento.

## Como executar o projeto

Quer executar o jogo localmente? Você precisará ter o [Node.js](https://nodejs.org/) e o npm instalados.

Com tudo configurado, siga os passos abaixo:

```bash
# Clone o repositório
git clone <this-repository-url>

# Entre na pasta do projeto
cd <repository-name>

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## Sobre o projeto

Monster Keeper ainda está em desenvolvimento e recebe melhorias constantes. Novas funcionalidades, ajustes nas mecânicas e correções de bugs fazem parte do processo de evolução do jogo.

A ideia é continuar aprimorando o projeto e transformar minhas ideias em uma experiência cada vez mais completa.
